## How I build

- **One problem, solved completely.** Each product does one job well before it does a second one.
- **No invented numbers.** Upfront never adds a figure you didn't give it, and nothing we publish quotes a statistic we can't source.
- **Fast and plain.** Pages that load quickly on a mid-range phone, and software a non-technical team can run without us.
